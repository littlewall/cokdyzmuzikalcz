# Co když..? - nový původní český muzikál

Projekt pro muzikál Co když..? - vizuální prezentace.

## Tech stack

- [Astro](https://astro.build/) s React integration
- [GSAP](https://greensock.com/gsap/) pro animace
- [LightningCSS](https://lightningcss.dev/) pro CSS
- [TypeScript](https://www.typescriptlang.org/)

## Development

```bash
yarn dev
```

## Build

```bash
yarn build
```
